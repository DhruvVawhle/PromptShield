# PromptShield — Source Notes

## Original Abstract

The uploaded `Major Project Abstract Updated.pdf` is the authoritative source for the original college-project requirements.

It states the title as:
**PromptShield – Detection and Prevention of Prompt Injection Attacks in Large Language Models**

It defines the selected domains as:
- AI
- ML
- NLP
- Generative AI & LLMs
- Cybersecurity

It describes the need for real-time detection, analysis, mitigation, sanitization, guardrails, explainable risk scoring, attack monitoring, and RBAC.

It specifies the baseline software stack:
- React.js
- Node.js + Express.js
- MongoDB
- Python 3.x
- Hugging Face Transformers
- LangChain
- Ollama / OpenAI API
- Docker
- Git/GitHub
- VS Code

It specifies baseline hardware:
- Windows 10/11 or Ubuntu
- Intel Core i5 10th Gen or higher
- 8 GB RAM minimum
- 256 GB SSD or higher
- Internet for API/dependency use
- GPU optional

The personal-project documentation in this package expands those requirements into an implementable architecture, API contract, database model, UI specification, security model, tests, and AI-coding-agent instructions.

## Important

Where the original abstract does not specify an implementation detail, the documentation marks it as an implementation direction rather than pretending that it came from the original college document.
